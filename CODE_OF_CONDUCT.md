# Code of Conduct

Klever Signal is a collaborative open-source project. Participants are expected to:

- be respectful, constructive, and specific;
- welcome different backgrounds and approaches;
- focus criticism on ideas, code, and evidence;
- protect private session and repository information; and
- accept correction when new evidence changes an interpretation.

Harassment, discrimination, threats, deliberate disclosure of private data, and bad-faith disruption are not acceptable. Project maintainers may remove content or restrict participation when needed to keep the project safe and productive.

Report conduct concerns privately through the security contact configured for the GitHub repository.
